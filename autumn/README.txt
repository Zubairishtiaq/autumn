1. DESCRIPTION
------------------------------------------------------------
Autumn is a modern, dark-themed creative portfolio HTML
template designed for designers, photographers, artists,
and creative agencies. It features a warm autumn-inspired
color palette with rich browns, deep charcoal, and soft
bronze accents.

Key features:
- Full-screen hero image slider with auto-play
- Filterable masonry portfolio grid
- Lightbox slideshow with keyboard navigation
- Team slider with hover social icons
- Auto-rotating full-width feature slider
- Parallax "TITLE" section
- Blog section with modal "Read More" popups
- FAQ accordion
- Testimonial cards
- Contact form with Google Maps
- Fully responsive design
- Sticky navbar with mobile hamburger menu

3. INSTALLATION
------------------------------------------------------------
1. Extract the .zip file to your desired location.
2. Open index.html in any modern web browser.
3. To deploy on a server, simply upload all files and
   folders to your web hosting (e.g., public_html).
4. No build tools, package managers, or server-side
   requirements are needed.


4. CUSTOMIZATION
------------------------------------------------------------
CHANGING CONTENT:
- Edit index.html directly to change text content.

CHANGING COLORS:
- Open assets/css/style.css and look for these values:
   • #0f0e0c  — Main dark background
   • #1a1714  — Navbar / card background
   • #d4b89b  — Bronze accent color
   • #3b1e8c  — Purple accent (buttons)
- Replace these hex values globally to change the palette.

CHANGING IMAGES:
- Search for "background-image: url(" in index.html.
- Replace each URL with your own hosted image.

CHANGING FONTS:
- The template uses "Inter" from Google Fonts.
- Replace the <link> in the <head> with your font of
  choice, then update the "font-family" in style.css.
